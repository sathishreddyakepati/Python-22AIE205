PYTHON + SQL (SQLite) - VS CODE DEMO
=========================================

Recommended demo order:

1. 01_connection.py
   - Connect Python to SQLite database.

2. 02_cursor_and_table.py
   - Create cursor.
   - Create students table.

3. 03_insert.py
   - Demonstrate INSERT.

4. 04_select.py
   - Demonstrate SELECT and fetchall().

5. 05_insert_multiple.py
   - Insert additional records.

6. 06_update.py
   - Demonstrate UPDATE.

7. 07_delete.py
   - Demonstrate DELETE.

8. 08_commit_and_rollback.py
   - Demonstrate rollback().

9. 09_complete_crud.py
   - Complete CRUD flow in one program.

10. 10_menu_driven_student_db.py
    - Small practical Student Database application.

IMPORTANT:
Run the files in the above order for the smoothest classroom demonstration.

If you want to restart the demo from the beginning, delete the
college.db file from the VS Code Explorer and run the files again.

No external Python package is required.
SQLite is available through Python's built-in sqlite3 module.
