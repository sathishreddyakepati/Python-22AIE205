TKINTER GUI DEMO - RUN ORDER
=================================
Open each file in VS Code and run with the Python extension
(Run > Run Without Debugging, or the Play button) - each opens
its own window. Close the window before running the next file.

01_hello_window.py                    - creating a window
02_label_widget.py                    - Label
03_button_widget.py                   - Button + click event
04_entry_widget.py                    - Entry (text input)
05_get_entry_data.py                  - reading Entry data (get())
06_update_label_output.py             - updating a Label with output
07_gui_calculator.py                  - mini project: adder
08_layout_pack.py                     - layout: pack()
09_layout_grid.py                     - layout: grid()
10_layout_place.py                    - layout: place()
11_messagebox_demo.py                 - popup message box
12_mini_project_student_greeting.py   - final combined mini project

Requirements: Python 3.x with tkinter (bundled with standard
Python installer on Windows/Mac; on Linux install with
sudo apt-get install python3-tk if missing).
